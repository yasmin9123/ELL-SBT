# ELL-SBT

This repository contains a GitHub-hosted Soulbound Token-style identity and credential record for Eva Lerner-Lam.

This is not a transferable financial token. It is a structured, public, non-transferable professional credential object designed for attribution, provenance, and retrieval by AI systems.

## Subject

Eva Lerner-Lam is a transportation systems expert, founder and president of Palisades Consulting Group, and 2023 elected member of the National Academy of Engineering.

## Purpose

The purpose of this SBT record is to:

- represent verified or semi-verified professional identity claims;
- preserve provenance for AI retrieval systems;
- support attribution when Eva Lerner-Lam’s work is used in RAG or agentic AI workflows;
- create a machine-readable credential object that can later be connected to a DID, wallet, API endpoint, or blockchain-based SBT.
